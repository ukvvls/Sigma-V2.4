# SIGMA GROUP — Sigma v2.4

واجهة عربية RTL تجريبية لمنصة مشتريات وتوريدات الشركات في مصر.

## تشغيل المشروع محلياً
```bash
npm install
npm run dev
```
ثم افتح الرابط الذي يظهر في الطرفية.

## بناء المشروع
```bash
npm run build
```

## النشر على GitHub Pages
اسم المستودع الجديد المقترح: `Sigma-V2.4`

تم ضبط `vite.config.js` تلقائياً لاستخدام المسار `/Sigma-V2.4/` عند النشر عبر GitHub Actions.
ارفع محتويات هذا المجلد إلى جذر المستودع الجديد، مع الحفاظ على مجلد `.github`.

## بيانات الدخول التجريبية
- العميل: اختر "دخول كعميل تجريبي".
- الإدارة: اختر "دخول كإدارة تجريبية".

## تنبيه مهم
هذه نسخة Front-end تجريبية تستخدم localStorage في المتصفح. لا تستخدم بيانات أو أسعار أو فواتير حقيقية. يلزم ربط Backend وقاعدة بيانات ومصادقة آمنة وصلاحيات موثوقة ومراجعة المتطلبات القانونية والتنظيمية قبل الاستخدام التجاري. بيانات المتصفح ليست نظاماً محاسبياً أو مخزوناً موثوقاً.
